## 三、测试与剩余风险说明

虽然本轮没有阻塞项，但正式 GPU 实验仍应保留以下边界说明：

1. B6 的 fake ASR/LLM 只验证线程和计时 bookkeeping，不验证真实模型的 WER、LLM 首 token 或 CUDA 调度；真实模型行为仍需由 E3/E5 运行结果检查。
2. tiny E2E artifact 是一次性结果，不是跨设备、跨重复运行的统计证据；论文中不能把它当作正式延迟数字。
3. `test_revision_regressions.py` 依赖本地 Silero VAD 缓存/下载，GPU 机首次运行前需要确保模型缓存可用或网络可达。
4. 正式 E5 结果仍必须检查：
   - 两张 GPU 的模型配置与论文锁定配置一致；
   - `audio_end_time - speech_end_time` 接近追加的 2 秒；
   - endpoint wait 的有效样本不包含 `asr_no_speech`；
   - `final_speech_segment_commit_time <= final_is_final_segment_enqueue_time`；
   - error 数量和异常样本已登记到 `REVISION_CHANGELOG.md`。
