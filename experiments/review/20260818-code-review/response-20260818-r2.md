## R2-P0-1：LocalAgreement 空识别后静默丢失文本 —— 接受，已修复

**修复**（`src/asr/local_agreement_streamer.py` `feed_segment()` 空识别分支）：

```python
if not cur_words:
    # 空识别（如纯静音段）：保留上一轮假设与 n_committed（append-only 状态不可回退）。
    self.new_audio = 0.0（解码前已重置）
    return []
```

只重置 `new_audio`，**不再清空 `prev_words`**，`n_committed` 维持。下一轮识别到词后与上一轮假设做 LCP，状态自然衔接；append-only 不变式不受影响。

**回归测试**（mock，3 个序列）：

1. **评审指定序列 1**（hello world → 空 → hello world again → hello world again more）：
   提交序列 `[], [], ['helloworld'], ['again']`，flush=`'more'`——空识别轮不破坏状态，`again`/`more` 不丢，`hello world` 仅提交一次，无重复。未发生状态重置，故无 reset 事件（符合"如果发生状态重置才有事件"的条件语义）。
2. **评审指定序列 2**（hello world → hello word → hello word again）：
   提交 `[], ['hello'], ['word']`，flush=`'again'`——append-only 保持。`world` 在该序列中从未被提交（仅是假设），不存在"已提交词被改写"，divergence=0 为正确行为（已与复审验收标准核对：该序列验证 append-only，失配记录由序列 3 覆盖）。
3. **失配触发变体**（提交 helloworldagain 后假设改为 wurst）：
   divergence 事件恰好 1 次（agreed=1 < committed=2），后续公共前缀重延伸恢复提交，flush 收尾，无死锁无重复。
