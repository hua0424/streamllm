# Author confirmation required before submission

The manuscript compiles with visible placeholders so that identities, legal rights, approvals, and relationships are not inferred. Resolve every item below before uploading to Editorial Manager.

## Title page

- [ ] Author names and publication order.
- [ ] Department, institution, postal address, city, postcode, and country.
- [ ] Corresponding author and active email.
- [ ] ORCID identifiers, if used.

## Declarations

- [ ] Acknowledgements, or explicitly confirm `None`.
- [ ] CRediT roles for each author.
- [ ] Funding bodies, grant numbers, and funder roles, or the no-specific-funding statement.
- [ ] Competing interests for every author, or the no-competing-interests statement.
- [ ] Institutional ethics/exemption/not-applicable determination and whether any human annotators participated outside the repository record.
- [ ] Full generative-AI/AI-assisted-tool disclosure covering code, analysis, figures, language editing, and manuscript preparation as required by Elsevier.

## Data and code availability

- [ ] Immutable public repository/archive URL, release/tag or commit, DOI if available, and access date.
- [ ] Repository rights holder and approved root license.
- [ ] Third-party notices for datasets, models, tokenizers, and software.
- [ ] Permission to redistribute the derived E3 input, or remove it from the public package and revise the statement.
- [ ] Identify any result or log files that cannot be public and state the factual reason.

## Final submission checks

- [ ] Replace every `[AUTHOR CONFIRM: ...]` and title-page placeholder in `main.tex` and `sections/07_declarations.tex`.
- [ ] Recompile and re-run all checks after metadata replacement.
- [ ] Upload `highlights.txt` as the mandatory separate editable Highlights file.
- [ ] Upload the LaTeX source, BibTeX database, class/style files, and each figure as a separate file.
- [ ] Select the Subscription publishing route after acceptance if zero APC publication is required.
- [ ] Do not request print-color reproduction unless its optional cost is acceptable; online color is sufficient.
