# 第二篇论文大纲

**建议题目**：播放感知的级联式流式语音对话上下文管理

**English title**: Playback-Aware Context Management for Cascaded Streaming Spoken Dialogue

**论文定位**：工程与系统型硕士论文。高层原则“对话历史应反映用户实际听到的内容”已有商用服务和开源框架实践；本文的贡献边界是公开级联栈中的播放位置关联、显式 KV 状态修正、角色恢复和受控量化评测。

### 1.1 研究背景与动机
- 级联语音对话的模块化优势与低延迟需求

- 扩展问题一：单一推测阈值下的计算浪费—有效 TTFT 权衡

### 1.3 本文工作与贡献
- C1：可作废的推测生成调度；强调真值终点接受和在线门控未实证

## 第三章 问题形式化

### 3.1 系统模型与异构进度
- ASR 稳定文本段、LLM token、TTS 文本片段、音频块和播放采样
- 原始进度不直接比较；映射到 token 域后描述顺序约束

### 3.2 播放边界与片段级历史一致性
- 片段级保留边界 $\widehat H(p)$
- 片段操作语义下的历史对齐
- 字符比例—空白边界代理；明确不是物理 token 真值

### 3.3 反向查询与 KV 合法性
- 片段记录关联与反向索引 $\Phi$
- 裁剪阶段：KV、掩码、账本端点一致
- 恢复阶段：角色串长度 $q$，下一轮 user 从 $N+q$ 开始

### 3.4 评测指标
- TTFT：触发口径与真值终点后的有效口径
- crop-only、角色恢复、组件中位数之和与完整 barge-in 链路的区分
- 片段口径与字符比例—空白边界近似口径
- 词面检测、LLM 裁判和人工样本均为代理，不称上下界
- 推测浪费率和离散工作点

## 第六章 实验与结果分析

### 6.1 研究问题与实验设置
- RQ1 一致性；RQ2 推测权衡；RQ3 组合响应；RQ4 KV 复用；RQ5 历史策略
- 清除 E2/E3 fixture 后按正式 MultiWOZ 报告
- 墙钟实测、微基准、画像建模和构造性结果分类
- 明确同步推测、40-token E3 上限和无真实 ASR 闭环

### 6.2 RQ1：播放感知历史一致性（E3）
- 100 条对话、每条件 400 场景
- 配对 McNemar + dialogue-cluster bootstrap
- B-gen：50.3% 词面、2.3% LLM 裁判
- B-ours 片段口径构造性零；字符比例—空白边界近似口径不作等价或因果结论
- 人工样本仅作非盲分层案例仲裁

### 6.3 RQ2：推测浪费—有效 TTFT（E2/A3）
- 九个离散点、每点 100
- 不推测 48.3 ms；$\theta=0.92$ 为 4.5%/12.1 ms
- 低阈值端非严格单调，不称连续 Pareto 前沿

### 6.4 RQ3：文本驱动模拟下的响应延迟（E1）
- 报均值、中位数、配对 bootstrap CI 和推测存活 99/100
- mouth-to-ear 为画像建模
- 未保存输入时长，不能完成长度斜率检验

### 6.5 RQ4：KV 复用微基准（A1）
- crop-only、角色恢复、两个组件中位数之和与重新预填充分开报告
- 8k 重新预填充中位数 / 组件中位数之和 = 39.7
- 不把 crop-only 解释为完整打断响应

### 6.6 RQ5：历史策略（A2）
- 描述性评分与重写耗时
- 仅 33/100 三策略 heard_text 相同，明确独立生成混杂
- 作为探索性负结果，不作因果比较

## 第七章 讨论

### 7.1 与已有系统的关系
- 公开研究实现与既有工程实践互补
- 不猜测商业系统内部实现

### 7.2 效度威胁
- 构念效度：边界代理、检测器、裁判、人工样本
- 内部效度：同步时序、随机生成、条件轨迹不一致、聚类
- 外部效度：单模型、单硬件、英文任务型对话、token 上限
- 结论效度：不显著不等于等价、原始重复和置信区间不足

### 7.3 可推广性与适用条件
- TTS 需提供片段—音频归属
- 推理引擎需支持缓存裁剪和角色恢复
- 阈值须按新领域和在线时序重新标定
