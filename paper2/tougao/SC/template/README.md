# Template provenance

Speech Communication accepts editable LaTeX source but its current Guide for Authors does not provide a journal-specific LaTeX class. The manuscript therefore uses Elsevier's official general-purpose `elsarticle` class in author--year mode, matching the journal's reference style.

Downloaded package:

- Source: CTAN mirror for Elsevier's `elsarticle` bundle
- URL: https://mirrors.ctan.org/macros/latex/contrib/elsarticle.zip
- Retrieved: 2026-09-04
- Bundle copyright: Elsevier Ltd., 2007--2026
- License: LaTeX Project Public License 1.3 or later, as stated by the bundle

The archive is retained as `elsarticle.zip` and extracted into `elsarticle/`. The manuscript package copies only the generated `elsarticle.cls` and `elsarticle-harv.bst` needed for portable compilation.
