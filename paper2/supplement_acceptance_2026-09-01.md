# 补实验验收报告（2026-09-01）

## 验收范围

本报告只验收 `experiments/sci34_supplement/` 的正式固定轨迹 E3、联合 A1 和 headless P1 v1，并给出是否可进入权威分章 Markdown 的结论。旧 E1/E2/A2 结果不重跑、不与补实验合并为同一总体。

## E3：接受

**结论**：固定轨迹 E3 接受为 RQ1 的主要受控结果。

- 100 条纯 MultiWOZ 对话，400 个配对场景，800 条条件记录，无 fixture。
- playback 与 generation 共享同一被打断 assistant token 轨迹、片段时间轴和注入位置；首轮及两轮 probes 均 greedy，最多 40 token。
- 片段目标 n=297：规则 playback 199/297（67.0%）、generation 189/297（63.6%），McNemar p=.164，generation−playback dialogue-cluster 95% CI [−9.5, 2.8] pp；裁判 127/297（42.8%）与 121/297（40.7%），p=.512，CI [−8.9, 6.1] pp。
- 字符比例—空白边界 proxy 应按自身非空目标确定资格。修正后 n=380：规则 286/380（75.3%）与 280/380（73.7%），p=.405，CI [−5.75, 2.50] pp；裁判 167/380（43.9%）与 157/380（41.3%），p=.229，CI [−8.25, 2.67] pp。
- 四个点估计均较小、方向与预设假设相反且不显著。允许的结论是“未检出预设方向的差异”；不允许优效、等效、非劣或伤害主张。
- dialogue-cluster bootstrap 是主要不确定性结果；exact McNemar 仅作描述性补充。
- 0.5 与 clean boundary 在片段目标层面重复，不能当作独立复制。
- playback 条件 400/400 个场景的局部完整未播放文本为空是单独的构造检查，不属于语义效果估计。
- 没有人类双标注。裁判为 Mistral 的单一 `specific-reference-v3` 提示词代理；v3 是在 v2 格式解析失败后加入首行 YES/NO 约束与一次有界重试的版本，正式运行无解析失败且未触发重试。

## A1：接受

**结论**：联合 A1 接受并替换正文旧 A1 结果。

协议为 256、512、1024、2048、4096、8192 token，裁去尾部 32 token；每点 warmup=5、repeats=50。计时使用 `perf_counter_ns`，设备前后同步；主要路径在同一计时区间内联合执行 crop 与角色恢复。原始 50 次重复已归档。

|---:|---:|---:|---:|
| 256 | 31.616 | 2.356 | 2.254× |
| 512 | 31.852 | 2.162 | 4.124× |

## P1 v1：不接受数值路径

**结论**：P1 v1 的 numeric joint path 判为协议无效，不进入摘要或正文结果表。

P1 v1 在每次 `fixture.ensure_full()` 后直接启动播放器，没有先等待异步 GPU 恢复完成；stop 后的首次设备同步因此把未完成的准备态计算错误计入 stop→crop 与 stop→role。原始记录中，受影响单元的额外等待跨 20 次重复持续，不能解释为只影响首个样本的 CUDA 冷启动，也不能通过事后挑选稳态单元或删除离群值修复。原始数据保留用于协议诊断，不作为当前论文证据。

**P1 v2 状态**：pending。prepared-state v2 已锁定为：播放器启动前同步完成 `ensure_full()`，单独记录 setup 与 stop 后同步耗时；每个未完成单元先做不落盘 warmup，并以 6 个片段下的 0.25/0.50/0.75 同时覆盖片段内与边界打断。正式重跑必须使用新 run ID。P1 v2 完成前，摘要和正文不放任何占位数字或推断值。

## Campaign 口径

旧 E1/E2/A2 与新 E3/A1 来自两轮 campaign。两轮 CPU 主机不同，但均使用同型号双 NVIDIA RTX 3090。旧 campaign 没有完整归档 CPU 型号，因此不补造 CPU 名称；两轮 campaign 的绝对墙钟时间不池化，只在各自协议内部比较。

## 最终验收

- A1：接受，替换旧独立组件中位数之和口径。
- P1 v1：joint 数值路径不接受，协议无效。
- P1 v2：pending，无正文或摘要占位数字。
